# Data Engineer Intern — BTS Group Holdings PCL

**July–November 2023 | Project: Data Quality Improvement**

## Project overview

Worked on improving data quality across selected data categories. The work began with exploratory analysis of representative entries, translated data issues into category-specific rules, implemented Python functions, reviewed uncovered cases, and refined the rules through repeated review.

## Work process

1. Explore representative examples by data category and identify inconsistent, malformed, or ambiguous values.
2. Define the expected handling and validation rules for each approved category.
3. Implement reusable Python functions for normalization and quality checks.
4. Review handled and unhandled cases; use uncovered cases to refine the rules.
5. Deliver the functions and supporting documentation for organizational review.
6. The work also involved an AWS/PySpark stage inside the organization environment. Its code and infrastructure are organization-owned; the organization's final validation/adoption status and production outcomes are not claimed here.

## Public project pages

- [Data Quality Improvement Project](data-quality-improvement/README.md)

The project page links to the public-safe category summaries for education, email, gender, income, marital status, and occupation. Its examples are independent demonstrations using synthetic values, not copies of the submitted code or data.

## Outcome

Delivered category-specific Python functions for organizational review and documented an iterative quality-rule workflow. No measured quality-improvement percentage, processing speedup, or final organizational adoption is claimed.

## Privacy boundary

The source sample contained real identifying values in some fields. No source rows, notebook outputs, real email addresses, names, identification numbers, or other direct identifiers are included here. Only approved category-level descriptions are represented, using synthetic example values.

# Data Engineer Intern — BTS Group Holdings PCL

**กรกฎาคม–พฤศจิกายน 2023 | โครงการ: Data Quality Improvement**

## ภาพรวมโครงการ

ทำงานปรับปรุงคุณภาพข้อมูลในหมวดที่กำหนด เริ่มจากสำรวจตัวอย่างข้อมูลเพื่อหาค่าที่ไม่สอดคล้อง ผิดรูปแบบ หรือกำกวม จากนั้นแปลงปัญหาเป็นกฎรายหมวด เขียนฟังก์ชัน Python ตรวจกรณีที่ยังจัดการไม่ได้ และปรับกฎซ้ำตามผลการตรวจทาน

## ขั้นตอนการทำงาน

1. สำรวจตัวอย่างข้อมูลแยกตามหมวด และระบุค่าที่ไม่สอดคล้อง ผิดรูปแบบ หรือกำกวม
2. กำหนดวิธีจัดการและกฎตรวจสอบของแต่ละหมวดที่ได้รับอนุญาตให้กล่าวถึง
3. เขียนฟังก์ชัน Python ที่นำกลับมาใช้ได้สำหรับปรับรูปแบบและตรวจคุณภาพข้อมูล
4. ตรวจกรณีที่จัดการได้และยังจัดการไม่ได้ แล้วนำกรณีที่หลุดไปปรับกฎ
5. ส่งมอบฟังก์ชันและเอกสารประกอบให้องค์กรตรวจสอบ
6. งานมีขั้นตอน AWS/PySpark ภายในสภาพแวดล้อมขององค์กร โดยโค้ดและระบบเป็นขององค์กร จึงกล่าวถึงเฉพาะภาพรวม และไม่กล่าวอ้างสถานะการตรวจรับ/นำไปใช้ขั้นสุดท้ายหรือผล production ที่ยังยืนยันไม่ได้

ส่งมอบฟังก์ชัน Python แยกตามหมวดให้องค์กรตรวจสอบ พร้อมอธิบายกระบวนการปรับกฎด้านคุณภาพข้อมูลเป็นรอบ ๆ ไม่มีการกล่าวอ้างเปอร์เซ็นต์การปรับปรุง ความเร็วที่เพิ่มขึ้น หรือสถานะการนำไปใช้ขั้นสุดท้ายที่ยังไม่มีข้อมูลยืนยัน
