# Gender Data Quality

**Scope:** standardizing categorical values across spelling, capitalization, and language variants that are approved for the project description.

**Approach:** normalize text, map known aliases to a consistent representation, and retain unmatched values for review rather than silently guessing.

**Public example:** invented values and mappings only. No person-level rows are included.

## ภาษาไทย

# การตรวจคุณภาพข้อมูล Gender

**ขอบเขต:** ปรับค่าหมวดหมู่ให้เป็นมาตรฐาน เมื่อสะกด ใช้ตัวพิมพ์ หรือใช้ภาษาต่างกัน ตามขอบเขตที่อนุญาตให้อธิบายใน Portfolio

**แนวทาง:** ปรับข้อความให้เป็นรูปแบบเดียว จับคู่ alias ที่ทราบกับค่ามาตรฐาน และเก็บค่าที่ไม่ตรงกับกฎไว้ทบทวน แทนการคาดเดาค่า

**ตัวอย่างสาธารณะ:** ใช้ค่าและ mapping ที่แต่งขึ้นเท่านั้น ไม่มีข้อมูลรายบุคคล
