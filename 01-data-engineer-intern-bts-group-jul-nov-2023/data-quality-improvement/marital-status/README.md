# Marital Status Data Quality

**Scope:** standardizing marital-status category values entered in different formats or languages.

**Approach:** normalize text and map known variants to a consistent category; review ambiguous values instead of assigning an unsupported result.

All examples are synthetic. Organization reference mappings are not published.

# การตรวจคุณภาพข้อมูล Marital Status
