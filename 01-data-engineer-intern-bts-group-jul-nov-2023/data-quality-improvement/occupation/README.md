# Occupation Data Quality

**Scope:** standardizing free-text occupation entries into consistent categories.

**Approach:** normalize text, apply approved mappings for known variants, and flag values that need further review. The public example uses a small invented dictionary and does not reproduce organization-specific categories.

## ภาษาไทย

# การตรวจคุณภาพข้อมูล Occupation

**ขอบเขต:** ปรับข้อความอาชีพที่กรอกอิสระให้เป็นหมวดที่สม่ำเสมอ

**แนวทาง:** ปรับข้อความ ใช้ mapping ที่อนุญาตสำหรับค่าที่รู้จัก และทำเครื่องหมายค่าที่ต้องทบทวน ตัวอย่างสาธารณะใช้พจนานุกรมขนาดเล็กที่แต่งขึ้น ไม่ทำซ้ำหมวดอาชีพเฉพาะขององค์กร
