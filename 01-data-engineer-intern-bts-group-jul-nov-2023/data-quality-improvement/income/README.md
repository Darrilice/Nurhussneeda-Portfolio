# Income Data Quality

**Scope:** normalize numeric and text-form income entries, including values expressed with separators or range-like wording.

**Approach:** identify the value pattern, normalize supported numeric/range formats, and flag ambiguous or unsupported cases for review. The public demonstration intentionally avoids organization thresholds and exact business rules.

No actual income values, source rows, or production rules are included.

## ภาษาไทย

# การตรวจคุณภาพข้อมูล Income

**ขอบเขต:** ปรับข้อมูลรายได้ที่บันทึกเป็นตัวเลขหรือข้อความ รวมถึงค่าที่มีตัวคั่นหรือเขียนในลักษณะช่วง

**แนวทาง:** ตรวจรูปแบบค่า ปรับรูปแบบตัวเลขหรือช่วงที่รองรับ และทำเครื่องหมายกรณีกำกวมหรือไม่ตรงกฎไว้ทบทวน ตัวอย่างสาธารณะจะไม่เปิดเผย threshold หรือกฎทางธุรกิจเฉพาะขององค์กร

ไม่มีค่ารายได้จริง แถวข้อมูลต้นทาง หรือกฎ production อยู่ในหน้านี้
