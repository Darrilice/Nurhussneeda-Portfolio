# Education Data Quality

**Scope:** standardizing education entries that may use different languages, spellings, or formats.

**Approach:** inspect value patterns, normalize text, map approved variants to a consistent label, and review values that do not match a known rule. The public code example uses an invented mapping and synthetic values only.

**Contribution:** Python/Pandas and regular-expression-based category normalization as part of the Data Quality Improvement work.

This page does not expose source records, organization-specific reference dictionaries, or the submitted implementation.

## ภาษาไทย

# การตรวจคุณภาพข้อมูล Education

**ขอบเขต:** ปรับรูปแบบข้อมูลการศึกษาให้เป็นมาตรฐาน แม้ข้อมูลต้นทางจะใช้หลายภาษา การสะกด หรือรูปแบบการกรอกที่ต่างกัน

**แนวทาง:** สำรวจรูปแบบค่า ปรับข้อความให้เป็นมาตรฐาน จับคู่ค่าที่ได้รับอนุญาตให้เผยแพร่กับ label กลาง และตรวจค่าที่ไม่ตรงกับกฎ ตัวอย่างโค้ดสาธารณะใช้ mapping ที่แต่งขึ้นและข้อมูลสังเคราะห์เท่านั้น

**ส่วนที่ทำ:** ใช้ Python/Pandas และ regular expressions เพื่อปรับข้อมูลรายหมวดในโครงการ Data Quality Improvement

หน้านี้ไม่เปิดเผยแถวข้อมูลจริง พจนานุกรมอ้างอิงเฉพาะขององค์กร หรือ implementation ที่ส่งมอบ
