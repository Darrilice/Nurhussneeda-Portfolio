# Project-based — Diabetes Data Profiling, Cleaning & Pre-processing

**October 2026 | Freelance**

## Project overview

Built a modular Python workflow to profile, clean, join, preprocess, validate, and export diabetes-related data for downstream analysis and model-training preparation. The codebase separates the main stages and records processing metadata. This work focused on preparing data; it does not claim that a model was trained as part of this project.

## Project areas

- [Cleaning and Preprocessing](cleaning-and-preprocessing/README.md) — end-to-end staged workflow and validation checks.
- [Unhandled Values](unhandled-values/README.md) — investigation of values that initial rules did not handle and iterative refinement of the workflow.
- [Medical Response Dataset](medical-response-dataset/README.md) — profiling and preparation of the response dataset for later model-training work.

## Outcome

Produced a repeatable and reviewable data-preparation workflow with explicit validation and exported metadata. No runtime, accuracy, or model-performance improvement is claimed without a verified measurement.

## Privacy boundary

The source project contains real medical data with identifying information removed. No source records, de-identified records, notebooks with outputs, medical schema, or model-training data are included in this public repository. Any demonstration code is independently written and uses synthetic records.

# Project-based — Diabetes Data Profiling, Cleaning & Pre-processing

## ภาพรวมโครงการ

พัฒนา workflow ด้วย Python แบบแบ่งโมดูล สำหรับ profiling, cleaning, join, preprocessing, validation และ export ข้อมูลที่เกี่ยวกับโรคเบาหวาน เพื่อเตรียมข้อมูลสำหรับการวิเคราะห์และการเตรียมฝึกโมเดลในขั้นต่อไป งานนี้เป็นการเตรียมข้อมูล ไม่ได้กล่าวอ้างว่ามีการฝึกโมเดลเป็นส่วนหนึ่งของโครงการ

## งานย่อย

- [Cleaning and Preprocessing](cleaning-and-preprocessing/README.md) — workflow ตั้งแต่ต้นจนจบและจุดตรวจสอบคุณภาพข้อมูล
- [Unhandled Values](unhandled-values/README.md) — ตรวจค่าที่กฎรอบแรกยังจัดการไม่ได้และปรับปรุง workflow เป็นรอบ ๆ
- [Medical Response Dataset](medical-response-dataset/README.md) — profiling และเตรียม response dataset สำหรับงานฝึกโมเดลในขั้นถัดไป

## ผลลัพธ์

ได้ workflow เตรียมข้อมูลที่ทำซ้ำและตรวจทานได้ มี validation ชัดเจน และส่งออก metadata การประมวลผล ไม่มีการกล่าวอ้างเวลา ความแม่นยำ หรือประสิทธิภาพโมเดลที่ยังไม่มีการวัดยืนยัน

## ขอบเขตความเป็นส่วนตัว

โปรเจกต์ต้นทางมีข้อมูลทางการแพทย์จริงที่นำข้อมูลระบุตัวตนออกแล้ว Repository สาธารณะนี้จะไม่มีแถวข้อมูลจริงหรือข้อมูลที่ปกปิดตัวตนแล้ว Notebook ที่มีผลลัพธ์ schema ทางการแพทย์ หรือข้อมูลสำหรับฝึกโมเดล ตัวอย่างโค้ดจะเขียนขึ้นใหม่และใช้ข้อมูลสังเคราะห์
