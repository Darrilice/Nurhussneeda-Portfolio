# Data Analyst & Data Engineer — ChulaPD

**March 2025–September 2026 | Excellence for Parkinson’s Disease & Related Disorders Center, King Chulalongkorn Memorial Hospital**

## Role overview

Worked across analytics, data engineering, and research support for the CheckPD programme. Responsibilities included gathering dashboard requirements, analyzing app usage and screening completion, cleaning incoming screening data through PostgreSQL automation, extracting features from sensor data with Python, collecting data at provincial sites, and contributing to a co-authored publication.

## Project areas

- [Data Analysis & Reporting](data-analysis-and-reporting/README.md) — EDA, source-data preparation, KPI and metric definitions, reporting logic, data dictionaries, and stakeholder requirements.
- [CheckPD Dashboard](dashboard/README.md) — translated user questions into dashboard views and analyses covering app adoption, assessment completion and drop-off, post-update comparisons, screening-risk results, and assessment patterns across clinical groups. The production dashboard is not displayed because it contains organization data.
- [Screening Data Cleaning + Trigger (PostgreSQL)](clean-data-trigger-postgresql/README.md) — automated cleaning of newly received records using SQL on Supabase PostgreSQL.
- [Sensor Feature Extraction (Python)](sensor-feature-extraction-python/README.md) — Python work to turn sensor signals into features for downstream analysis. Production data and code are excluded.
- [Research and Publication](research-and-publication/README.md) — provincial field data collection and direct contributions to the CheckPD manuscript’s figures and tables.

## Outcome

Connected user requirements, data preparation, and analysis outputs within a healthcare screening programme. Specific operational counts or improvements are not claimed unless they are publicly reported and attributable to the stated scope.

## Privacy boundary

The underlying data and code are production materials belonging to the organization. This portfolio contains no production extracts, dashboards, screenshots, source code, database schema, credentials, participant-level data, or internal infrastructure details. Any code example is independently written and uses synthetic data.
