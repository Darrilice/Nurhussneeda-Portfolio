# Sensor Feature Extraction — Python

## Scope

Used Python to extract features from sensor data for downstream analysis. The source implementation, sensor files, feature tables, and production validation results belong to the organization and are not included in this portfolio.

## Public demonstration

The [synthetic signal example](examples/synthetic_signal_features.py) creates a mathematical signal from scratch and extracts a few general descriptive features. It illustrates the concept of feature extraction only; it is not a copy of the production feature set or algorithm.

## What is intentionally not shown

- Production sensor recordings or derived feature values
- Organization-specific feature definitions, thresholds, or signal-processing choices
- Production code, file formats, model inputs, or evaluation results

The scope and outcome of this page are limited to details that can be described without revealing the production implementation.

# Sensor Feature Extraction — Python

## ขอบเขตงาน

ใช้ Python สกัด feature จากข้อมูล sensor เพื่อนำไปวิเคราะห์ต่อ โดยไม่ใส่ implementation ไฟล์ sensor ตาราง feature หรือผลตรวจสอบ production เพราะเป็นข้อมูลและโค้ดขององค์กร

## ตัวอย่างสาธารณะ

[ตัวอย่างสัญญาณสังเคราะห์](examples/synthetic_signal_features.py) สร้างสัญญาณทางคณิตศาสตร์ขึ้นใหม่และคำนวณ feature เชิงสรุปพื้นฐานบางรายการ ใช้แสดงแนวคิดการสกัด feature เท่านั้น ไม่ใช่ชุด feature หรืออัลกอริทึมจาก production

## รายละเอียดที่ไม่นำมาแสดง

- สัญญาณ sensor จริงหรือค่า feature ที่สกัดจากข้อมูลจริง
- นิยาม feature, threshold หรือวิธีประมวลผลสัญญาณเฉพาะขององค์กร
- โค้ด production รูปแบบไฟล์ ข้อมูลนำเข้าโมเดล หรือผลประเมิน
