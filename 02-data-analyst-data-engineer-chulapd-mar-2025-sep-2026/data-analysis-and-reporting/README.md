# Data Analysis & Reporting

## Scope

Supported analysis and reporting across structured and time-series data received through spreadsheet and digital collection channels. The work included exploratory analysis, transformation and quality checks, KPI reporting, visualization, and documenting definitions used by the team.

## Requirements and documentation

- Gathered and clarified the questions collaborators needed reports to answer.
- Helped define metrics and document calculation/reporting logic.
- Prepared data dictionaries and shared definitions to make report interpretation more consistent.
- Supported KPI reports, dashboards, and data visualizations.

## Public-safe representation

This page describes the analysis and reporting responsibilities without exposing the production dashboard, source files, real schemas, exact internal metric values, or participant-level data. Any future example will use synthetic data and independently written code.

## ขอบเขตงาน

สนับสนุนการวิเคราะห์และรายงานข้อมูลแบบมีโครงสร้างและข้อมูลตามช่วงเวลา ซึ่งมาจากสเปรดชีตและช่องทางเก็บข้อมูลดิจิทัล งานประกอบด้วย EDA การแปลงและตรวจคุณภาพข้อมูล การทำ KPI report ภาพแสดงข้อมูล และการบันทึกนิยามที่ทีมใช้ร่วมกัน

## Requirement และเอกสารประกอบ

- รับและทำความเข้าใจคำถามที่ผู้เกี่ยวข้องต้องการให้รายงานตอบ
- ช่วยกำหนด metric และบันทึกตรรกะการคำนวณ/การรายงาน
- จัดทำ data dictionary และนิยามร่วม เพื่อให้ตีความรายงานได้สอดคล้องกันขึ้น
- สนับสนุน KPI report, Dashboard และ data visualization

## ขอบเขตที่เผยแพร่ได้

หน้านี้อธิบายหน้าที่วิเคราะห์และรายงาน โดยไม่เปิดเผย Dashboard production ไฟล์ต้นทาง schema จริง ค่า metric ภายใน หรือข้อมูลรายผู้เข้าร่วม ตัวอย่างในอนาคตจะใช้ข้อมูลสังเคราะห์และโค้ดที่เขียนขึ้นใหม่
